1-4 IPv6アドレス

頻出 IPv6の基礎・アドレス種別・EUI-64を理解する

🌐IPv6の基礎

IPv4 vs IPv6

項目 IPv4 IPv6
アドレス長 32ビット 128ビット
表記 10進ドット区切り (192.168.1.1) 16進コロン区切り (2001:db8::1)
アドレス数 約43億 約340澗（3.4×10³⁸）
ブロードキャスト あり なし（マルチキャストで代替）
NAT 必要 不要（アドレス枯渇なし）
ヘッダ 可変長（20〜60バイト） 固定40バイト

IPv6アドレスの表記ルール

省略ルール（2つのルール）

  • ルール1：各グループの先頭ゼロは省略可。0db8→db8
  • ルール2：連続する0グループは「::」で1か所だけ省略可。0000:0000:0000→::
完全形: 2001:0db8:0000:0000:0000:0000:0000:0001
省略形: 2001:db8::1

IPv6アドレスの種別

種別 プレフィックス 用途
グローバルユニキャスト 2000::/3 インターネット上で一意。IPv4のパブリックIPに相当
リンクローカル FE80::/10 同一リンク内のみ有効。自動生成される
ユニークローカル FC00::/7 プライベートネットワーク内。IPv4プライベートIPに相当
マルチキャスト FF00::/8 複数宛先への一括送信
エニーキャスト ユニキャストと同じ 最近傍ノードへ送信
ループバック ::1/128 自分自身（IPv4の127.0.0.1に相当）

EUI-64によるインタフェースID生成

EUI-64の計算手順

  1. MACアドレス（48ビット）を取得（例：AA:BB:CC:DD:EE:FF）
  2. 中央に「FFFE」を挿入→ AA:BB:CC:FF:FE:DD:EE:FF
  3. 先頭バイトの第7ビット（U/Lビット）を反転→ A8:BB:CC:FF:FE:DD:EE:FF
  4. この64ビットをインタフェースIDとして使用
MAC:  AA:BB:CC:DD:EE:FF
EUI-64インタフェースID: A8BB:CCFF:FEDD:EEFF
📌 試験ポイント
リンクローカルアドレスはOSPFv3のネイバー確立など、同一リンク内通信に必ず使用される。show ipv6 interfaceで確認できる。

✏️ 確認問題（第1-4章）

Q1. IPv6のリンクローカルアドレスのプレフィックスとして正しいものはどれか？
正解：C（FE80::/10）
リンクローカルアドレスはFE80::/10のプレフィックスを持ち、同一リンク内通信にのみ使用されます。
Q2. IPv6でブロードキャストが廃止された代わりに使用されるものはどれか？
正解：B（マルチキャスト）
IPv6ではブロードキャストが廃止され、マルチキャストがその役割を担います。例えば全ルータ宛のFF02::2などが使われます。

1-5 TCP・UDP・ポート番号

頻出 トランスポート層のプロトコルと主要ポート番号を覚える

🔄TCP vs UDP

特徴 TCP UDP
接続確立 3ウェイハンドシェイク（コネクション型） コネクションレス型
信頼性 高い（再送制御・順序制御） 低い（再送なし）
速度 遅い（オーバーヘッドあり） 速い
フロー制御 あり（ウィンドウサイズ） なし
主な用途 HTTP/S、FTP、SSH、SMTP DNS、DHCP、SNMP、VoIP、動画ストリーミング

TCPの3ウェイハンドシェイク

クライアント          サーバー
   |── SYN ──────────→ |  (接続要求)
   |← SYN-ACK ────── |  (受入+確認)
   |── ACK ──────────→ |  (確認応答)
   |                   |  (接続確立！)

主要ポート番号（必須暗記）

ポート番号 プロトコル 説明 TCP/UDP
20, 21 FTP ファイル転送（20:データ、21:制御） TCP
22 SSH 暗号化リモートアクセス TCP
23 Telnet 平文リモートアクセス（非推奨） TCP
25 SMTP メール送信 TCP
53 DNS ドメイン名解決 UDP/TCP
67, 68 DHCP IPアドレス自動割当（67:サーバー、68:クライアント） UDP
69 TFTP 簡易ファイル転送 UDP
80 HTTP Web通信（平文） TCP
110 POP3 メール受信 TCP
123 NTP 時刻同期 UDP
161, 162 SNMP ネットワーク管理（161:ポーリング、162:トラップ） UDP
443 HTTPS Web通信（暗号化） TCP
514 Syslog ログ転送 UDP

✏️ 確認問題（第1-5章）

Q1. TCPの「3ウェイハンドシェイク」で、サーバーが最初にクライアントへ返すパケットはどれか？
正解：B（SYN-ACK）
クライアントがSYNを送り、サーバーがSYN-ACKで応答し、クライアントがACKを送って接続確立（SYN→SYN-ACK→ACK）。
Q2. DHCPで使用されるポート番号として正しい組み合わせはどれか？
正解：A（67/68 UDP）
DHCPサーバーはポート67、クライアントはポート68を使用します。プロトコルはUDPです。
Q3. 次のうちUDPを使用するプロトコルはどれか？
正解：C（SNMP）
SNMPはポート161/162でUDPを使用します。HTTP・SSH・FTPはTCPです。

📌 ストレートケーブル vs クロスケーブル
現代のスイッチはAuto-MDIX（自動判別）搭載のため基本的にどちらでもOK。試験ではストレート=異種機器間、クロス=同種機器間と覚える。

💡光ファイバーケーブル

種別 コア径 光源 主な用途 最大距離
シングルモード (SMF) 9μm レーザー 長距離WAN 〜100km以上
マルチモード (MMF) 50/62.5μm LED LAN・データセンター 〜2km

⚡PoE（Power over Ethernet）

  • PoE（802.3af）：最大15.4W供給（APや小型IPカメラ向け）
  • PoE+（802.3at）：最大30W供給（より高出力のAP向け）
  • PoE++（802.3bt）：最大60/100W供給（PTZカメラ・小型PC向け）

✏️ 確認問題（第1-6章）

Q1. 長距離WAN接続に適した光ファイバーの種類はどれか？
正解：B（シングルモード）
SMFはレーザー光源を使い100km以上の長距離伝送が可能です。MMFはLAN内の短距離向けです。

2.4GHz帯の非重複チャネル

🚨 最重要暗記事項
2.4GHz帯の非重複チャネルは1・6・11（日本）の3チャネル。隣接するAPにはこの3つを割り当て干渉を防ぐ。5GHz帯は多数のチャネルがあるため干渉しにくい。

無線セキュリティ方式

方式 暗号化 安全性
WEP RC4（40/104bit） 非常に低い（使用禁止）
WPA TKIP 低い（非推奨）
WPA2 AES-CCMP 高い（現在の標準）
WPA3 AES-GCMP 非常に高い（最新標準）

✏️ 確認問題（第1-7章）

Q1. 2.4GHz帯における非重複チャネルの正しい組み合わせはどれか？
正解：C（1・6・11）
2.4GHz帯は各チャネルが重複するため、非重複チャネルは1・6・11の3つだけです。隣接するAPはこの3チャネルを使い分けて干渉を回避します。

1-8 スイッチング基礎・MACアドレス

頻出 スイッチの動作原理とMACアドレステーブルを理解する

🔀スイッチの転送動作

MACアドレステーブルの動作（4ステップ）

  1. 学習（Learning）：受信フレームの送信元MACと受信ポートをテーブルに記録
  2. エージング（Aging）：一定時間（300秒）通信のないエントリを自動削除
  3. フィルタリング（Filtering）：送信元と宛先が同じポートならフレームを破棄
  4. フォワーディング/フラッディング：宛先MACがテーブルにあれば該当ポートへ転送、なければ全ポートへフラッド

フレームの転送方式

方式 特徴 遅延
ストアアンドフォワード フレーム全体受信後にFCSエラーチェックしてから転送。エラー検出あり 最大
カットスルー 宛先MACアドレス（先頭6バイト）を読んだ時点で転送開始。エラー検出なし 最小
フラグメントフリー 先頭64バイト受信後に転送。衝突による不正フレームを除去 中間

重要なCiscoコマンド

Switch# show mac address-table       # MACアドレステーブル確認
Switch# show interfaces              # インタフェース状態確認
Switch# show interfaces status        # インタフェース一覧・速度・duplex
Switch(config-if)# speed 100       # 速度設定（10/100/1000/auto）
Switch(config-if)# duplex full     # 全二重設定
⚠️ デュプレックスミスマッチ
一方がfull、他方がhalfだと遅延・エラーが多発する。両端を同じ設定にするか、両端ともautoに設定する。

✏️ 確認問題（第1-8章）

Q1. スイッチが宛先MACアドレスをMACアドレステーブルで見つけられない場合、どのような動作をするか？
正解：A（フラッド）
宛先MACが不明な場合、スイッチは受信ポート以外の全ポートへフレームをフラッド（送信）します。これをユニキャストフラッディングと呼びます。
Q2. フレーム全体を受信してからFCSエラーチェックを行い転送するスイッチ方式はどれか？
正解：A（ストアアンドフォワード）
ストアアンドフォワード方式はフレーム全体を受信後にFCSエラーチェックを行います。信頼性が最も高いが遅延が最大です。
