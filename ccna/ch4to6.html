4-1 NAT・PAT

頻出設定

🔁NATの種類

種類 説明
スタティックNAT プライベートIP ↔ グローバルIPを1対1で固定変換
ダイナミックNAT プールのグローバルIPを動的に割り当て（1対1）
PAT（NATオーバーロード） 多数のプライベートIPを1つのグローバルIPとポート番号で変換。最も一般的

NATの用語

  • Inside Local：内部のプライベートIPアドレス
  • Inside Global：外部から見た内部ホストのグローバルIP
  • Outside Global：外部サーバーのグローバルIP
  • Outside Local：内部から見た外部サーバーのIP（通常Outside Globalと同じ）

PAT設定（最も重要）

# インタフェース指定（よく使われる方法）
Router(config)# interface GigabitEthernet0/0  # 内部
Router(config-if)# ip nat inside
Router(config)# interface GigabitEthernet0/1  # 外部
Router(config-if)# ip nat outside
Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255
Router(config)# ip nat inside source list 1 interface GigabitEthernet0/1 overload
Router# show ip nat translations

✏️ 確認問題（第4-1章）

Q1. 多数の内部ホストが1つのグローバルIPでインターネットに接続するNAT方式はどれか？
正解：C（PAT）
PATはポート番号を使って多対1の変換を行い、1つのグローバルIPで多数の内部ホストがインターネット接続できます。

4-2 DHCP・DNS

設定

📋DHCP

DHCPの動作（DORA）

  1. Discover：クライアントがブロードキャストでDHCPサーバーを探す
  2. Offer：DHCPサーバーがIPアドレスを提案
  3. Request：クライアントが提案を承認
  4. Acknowledge：サーバーが確定通知を送信

CiscoルータをDHCPサーバーとして設定

Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10
Router(config)# ip dhcp pool MYPOOL
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8
Router(dhcp-config)# lease 1  # リース期間1日

# DHCPリレーエージェント（別セグメントへのDHCP転送）
Router(config-if)# ip helper-address 10.1.1.100
Router# show ip dhcp binding

🌐DNS

DNS（Domain Name System）はFQDN（完全修飾ドメイン名）をIPアドレスに変換します。ポート53（UDP/TCP）を使用。再帰的クエリと反復的クエリがある。

✏️ 確認問題（第4-2章）

Q1. DHCPのDORAプロセスでクライアントが最初に送信するメッセージはどれか？
正解：B（Discover）
DHCPはDiscover→Offer→Request→Acknowledgeの順（DORA）。最初にクライアントがDiscoverをブロードキャストします。
Q2. 異なるサブネットのクライアントへDHCPを提供するために設定するのはどれか？
正解：C（ip helper-address）
DHCPリレーエージェントとして「ip helper-address DHCPサーバーのIP」を設定することで、ブロードキャストを別セグメントのDHCPサーバーにユニキャストで転送します。

概念

⏱️NTP（Network Time Protocol）

ネットワーク機器の時刻を同期するプロトコル。ポートUDP 123を使用。

Router(config)# ntp server pool.ntp.org
Router# show ntp status
Router# show ntp associations

📝Syslog（ログ管理）

レベル 名称 説明
0 Emergency システム使用不能
1 Alert 即時対応が必要
2 Critical 重大な状況
3 Error エラー状態
4 Warning 警告
5 Notice 注意すべき正常な状態
6 Informational 情報メッセージ
7 Debug デバッグメッセージ

「Every Awful Crisis Ends With Notable Innovative Decisions」（順番：0〜7）

📊SNMP

  • ポートUDP 161（Get/Set）、UDP 162（Trap）
  • Get：マネージャーがエージェントに情報を要求
  • Trap：エージェントが異常をマネージャーへ自発的に通知
  • SNMPv3：認証・暗号化あり（USM）→セキュリティに優れる

Q1. Syslogのログレベルで「3」が示すものはどれか？
正解：C（Error）
レベル0=Emergency、1=Alert、2=Critical、3=Error、4=Warning、5=Notice、6=Informational、7=Debug。

4-4 QoS・TFTP/FTP

概念

📶QoS（Quality of Service）

PHB（Per-Hop Behavior）の種類

種類 用途
EF（Expedited Forwarding） 最優先転送。VoIPなどのリアルタイムトラフィック
AF（Assured Forwarding） 4つのクラス（AF1〜4）各3レベルの廃棄優先度
BE（Best Effort） デフォルト。優先なし

📁TFTP・FTP・SFTP

プロトコル ポート 暗号化 認証
TFTP UDP 69 なし なし
FTP TCP 20/21 なし あり
SFTP TCP 22 SSH暗号化 あり

✏️ 確認問題（第4-4章）

Q1. VoIPなどのリアルタイムトラフィックに最適なQoS PHBはどれか？
正解：A（EF）
EFは最優先転送で低遅延・低ジッターが必要なVoIPに最適です。

5-1 セキュリティ概念・脅威

概念

⚠️主な脅威・攻撃の種類

攻撃 説明
DoS/DDoS サービス妨害攻撃。大量パケットでリソースを枯渇
スプーフィング 送信元IPやMACを偽装
フィッシング 偽サイト・メールで認証情報を詐取
中間者攻撃（MitM） 通信の盗聴・改ざん
バッファオーバーフロー メモリ境界を超えたデータで任意コード実行
パスワードアタック ブルートフォース・辞書攻撃
マルウェア ウィルス・ワーム・トロイの木馬・ランサムウェア

CIAトライアド（情報セキュリティの3要素）

  • Confidentiality（機密性）：許可された者のみがアクセスできる
  • Integrity（完全性）：データが正確で改ざんされていない
  • Availability（可用性）：必要な時にシステムを利用できる

✏️ 確認問題（第5-1章）

Q1. 情報セキュリティの「CIAトライアド」のIが意味するものはどれか？
正解：B（Integrity）
CIAはConfidentiality（機密性）・Integrity（完全性）・Availability（可用性）の頭文字です。

5-2 ACL（アクセスコントロールリスト）

頻出設定

🚦ACLの基礎

種類 番号 マッチ対象
標準ACL（Standard） 1〜99、1300〜1999 送信元IPのみ
拡張ACL（Extended） 100〜199、2000〜2699 送信元IP、宛先IP、プロトコル、ポート番号
🚨 ACL配置の原則
  • 標準ACL：宛先に近い場所に配置（送信元しか見ないため）
  • 拡張ACL：送信元に近い場所に配置（早期フィルタリング）
  • 暗黙のdeny any：全ACLの最後に自動追加される

ACL設定コマンド

# 標準ACL（番号形式）
Router(config)# access-list 10 permit 192.168.1.0 0.0.0.255
Router(config)# access-list 10 deny any

# 拡張ACL（名前形式・推奨）
Router(config)# ip access-list extended BLOCK_HTTP
Router(config-ext-nacl)# deny tcp 192.168.1.0 0.0.0.255 any eq 80
Router(config-ext-nacl)# permit ip any any

# インタフェースへ適用
Router(config-if)# ip access-group BLOCK_HTTP in   # inbound
Router(config-if)# ip access-group 10 out            # outbound
Router# show ip access-lists

✏️ 確認問題（第5-2章）

Q1. 標準ACLはどこに配置するのが推奨されるか？
正解：A（宛先に近い場所）
標準ACLは送信元IPのみでフィルタリングするため、宛先近くに置かないと意図しないトラフィックもブロックする恐れがあります。
Q2. 拡張ACLの番号範囲として正しいのはどれか？
正解：B（100〜199）
標準ACL=1〜99（および1300〜1999）、拡張ACL=100〜199（および2000〜2699）です。

5-4 L2セキュリティ

頻出設定 DHCPスヌーピング・DAI・ポートセキュリティ

🛡️DHCPスヌーピング

不正なDHCPサーバーからの応答をブロック。Trusted/Untrustedポートで制御。

Switch(config)# ip dhcp snooping
Switch(config)# ip dhcp snooping vlan 10
Switch(config-if)# ip dhcp snooping trust  # 上位スイッチ/DHCPサーバー向けポート

🔒DAI（Dynamic ARP Inspection）

ARPスプーフィングを防ぐ。DHCPスヌーピングバインディングテーブルでARP検証。

Switch(config)# ip arp inspection vlan 10
Switch(config-if)# ip arp inspection trust  # 信頼できるポート

🔐ポートセキュリティ（Port Security）

Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
Switch(config-if)# switchport port-security maximum 2
Switch(config-if)# switchport port-security violation restrict
Switch(config-if)# switchport port-security mac-address sticky
Switch# show port-security interface Gi0/1

違反アクション（Violation Mode）

  • Protect：違反フレーム破棄、ログなし
  • Restrict：違反フレーム破棄、ログ・SNMPトラップ送信
  • Shutdown（デフォルト）：ポートをerr-disabledにシャットダウン

✏️ 確認問題（第5-4章）

Q1. ポートセキュリティのデフォルトの違反アクションはどれか？
正解：C（Shutdown）
デフォルトはShutdownで、違反が発生するとポートがerr-disabled状態になります。err-disabledからの復旧はshutdown→no shutdownが必要です。

5-5 VPN・AAA

概念

🔒VPN（Virtual Private Network）

種類 説明
サイト間VPN 拠点間の常時接続。IPsecトンネルで暗号化
リモートアクセスVPN 個人ユーザーが社内ネットワークにアクセス（SSL VPN / IPsec）

🔐AAA（認証・認可・アカウンティング）

  • Authentication（認証）：誰か？を確認（ユーザー名・パスワード）
  • Authorization（認可）：何をしてよいか？を制御
  • Accounting（アカウンティング）：何をしたか？を記録
プロトコル ポート 暗号化 特徴
RADIUS UDP 1812/1813 パスワードのみ IEEE標準。主にネットワークアクセス認証
TACACS+ TCP 49 全パケット Cisco独自。管理者アクセス制御に優れる

✏️ 確認問題（第5-5章）

Q1. AAAの「A」のうち、「ユーザーが何をしてよいか制御する」機能はどれか？
正解：B（Authorization）
AuthorizationはACLやコマンド制御でユーザーが実行できる操作を制御します。

6-1 ネットワーク自動化概要

概念

🤖従来型 vs コントローラベース

項目 従来型ネットワーク コントローラベース（SDN）
設定管理 機器ごとに個別CLI設定 中央コントローラから一括設定
スケーラビリティ 低い（機器増加で管理複雑化） 高い（自動プロビジョニング）
柔軟性 低い 高い（プログラム可能）

SDNの3層アーキテクチャ

  • アプリケーション層：ビジネスアプリ・ネットワーク管理ツール
  • コントロール層：SDNコントローラ（Cisco APIC等）。ネットワーク全体を把握
  • インフラ層：物理スイッチ・ルータ。コントローラの指示に従い転送

✏️ 確認問題（第6-1章）

Q1. SDNアーキテクチャで、物理スイッチ・ルータが存在する層はどれか？
正解：B（インフラ層）
SDNの3層：アプリケーション層（アプリ）→コントロール層（コントローラ）→インフラ層（物理機器）。

6-2 REST API・JSON

概念

🔌REST API

REST APIの特徴

  • HTTP動詞：GET（取得）、POST（作成）、PUT（更新）、DELETE（削除）、PATCH（一部更新）
  • ステートレス：各リクエストは独立（セッション状態を保持しない）
  • データ形式：主にJSONまたはXML

      {"name": "GigabitEthernet0/1", "ip": "192.168.1.1", "mask": "255.255.255.0"}
    ],
    "ospf_enabled": true
  }
}

✏️ 確認問題（第6-2章）

Q1. REST APIでリソースの情報を取得する際に使用するHTTPメソッドはどれか？
正解：A（GET）
GET=取得、POST=作成、PUT=更新（全体）、PATCH=更新（一部）、DELETE=削除。

6-3 Ansible・Puppet・Chef

概念

⚙️設定管理ツールの比較

項目 Ansible Puppet Chef
アーキテクチャ エージェントレス エージェント型 エージェント型
設定言語 YAML（Playbook） Puppet DSL (Ruby系) Ruby (Cookbook)
