2-1 VLAN基礎・設定

頻出設定 VLANの概念と基本設定コマンドをマスターする

🏷️VLANとは

VLAN（Virtual LAN）は、物理的な配線に関係なく論理的にネットワークを分割する技術です。同一VLAN内の機器はL2で通信でき、異なるVLAN間の通信にはルータ（またはL3スイッチ）が必要です。

VLANのメリット

  • セキュリティ向上：部門ごとにVLANを分けてトラフィックを隔離
  • ブロードキャストドメインの縮小：不要なブロードキャストを制限しパフォーマンス向上
  • 柔軟な管理：物理的な移動なしに論理的なグループ変更が可能

VLAN番号の分類

VLAN番号 種別 説明
1 デフォルトVLAN 全ポートのデフォルト。削除不可
2〜1001 通常VLAN（Normal Range） ユーザー定義可能。VTP対応
1002〜1005 予約済み レガシーTR/FDDI用。削除不可
1006〜4094 拡張VLAN（Extended Range） VTPトランスペアレントモードのみ

VLAN設定コマンド

# VLANデータベースへ登録
Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config-vlan)# exit

# アクセスポートへのVLAN割り当て
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

# 確認コマンド
Switch# show vlan brief
Switch# show vlan id 10
Switch# show interfaces GigabitEthernet0/1 switchport

✏️ 確認問題（第2-1章）

Q1. 異なるVLAN間で通信するために必要なものはどれか？
正解：C（ルータまたはL3スイッチ）
VLANはL2でブロードキャストドメインを分割します。異なるVLAN間の通信にはL3でのルーティングが必要です。
Q2. CiscoスイッチでVLAN 20を作成し「Engineering」と名前を付けるコマンドとして正しいのはどれか？
正解：B
VLAN作成はグローバルコンフィグモードで「vlan 番号」と入力し、vlan-configモードで「name 名前」と設定します。

2-2 トランクポート・802.1Q

頻出設定 複数VLANを1本のリンクで伝送するトランキング技術

🔗トランクとは

トランクポートは複数のVLANのトラフィックを1本のリンクで伝送するポートです。スイッチ間、またはスイッチとルータ間の接続に使用します。

802.1Q（IEEE標準）

タグ付きフレームの構造

通常フレーム:   [宛先MAC][送信元MAC][EtherType][データ][FCS]
802.1Qフレーム: [宛先MAC][送信元MAC][802.1Qタグ(4byte)][EtherType][データ][FCS]
                                      └─ TPID(0x8100) + PCP(3bit) + DEI(1bit) + VLAN ID(12bit)

ネイティブVLAN：タグなしで送受信されるVLAN（デフォルトはVLAN 1）。両端で一致させる必要がある。

トランク設定コマンド

Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk encapsulation dot1q  # 一部機種のみ必要
Switch(config-if)# switchport trunk native vlan 99
Switch(config-if)# switchport trunk allowed vlan 10,20,30

# 確認
Switch# show interfaces trunk

Router-on-a-Stick（ルータの1アームルーティング）

# ルータ側のサブインタフェース設定
Router(config)# interface GigabitEthernet0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0

Router(config)# interface GigabitEthernet0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0

✏️ 確認問題（第2-2章）

Q1. 802.1Qトランクにおいてタグなしで送受信されるVLANを何というか？
正解：C（ネイティブVLAN）
ネイティブVLANのフレームは802.1Qタグなしでトランクリンクを通過します。両端で一致しないとVLAN不一致の問題が起きます。

2-3 EtherChannel (LACP)

設定 複数の物理リンクを1本の論理リンクに束ねる技術

⛓️EtherChannelとは

EtherChannelは複数の物理リンクを1つの論理リンクとして束ねる技術です。帯域幅の増加と冗長性を同時に実現します。

ネゴシエーションプロトコル

プロトコル 標準 モード 説明
LACP IEEE 802.3ad active / passive 業界標準。activeが交渉を開始
PAgP Cisco独自 desirable / auto Cisco機器間でのみ動作。desirableが交渉を開始
Static — on ネゴシエーションなし。両端onが必要

EtherChannel設定（LACP）

Switch(config)# interface range GigabitEthernet0/1 - 2
Switch(config-if-range)# channel-group 1 mode active    # LACP active
Switch(config-if-range)# exit
Switch(config)# interface port-channel 1
Switch(config-if)# switchport mode trunk

# 確認
Switch# show etherchannel summary
Switch# show etherchannel port-channel

✏️ 確認問題（第2-3章）

Q1. EtherChannelでIEEE 802.3adに基づく標準プロトコルはどれか？
正解：A（LACP）
LACPはIEEE 802.3adの標準プロトコルで、異なるベンダー間でも動作します。PAgPはCisco独自です。

2-4 スパニングツリープロトコル (STP)

頻出 L2ループを防ぐSTPの動作・ポートロール・状態遷移を理解する

🌳STPの目的

L2ネットワークでは冗長リンクがあるとブロードキャストストームやMACアドレステーブルの不安定化が起きます。STPは一部ポートをブロッキングして論理的にループのないトポロジを作ります。

STPの選定プロセス

  1. ルートブリッジの選出：最小のブリッジID（プライオリティ+MACアドレス）を持つスイッチ
  2. ルートポートの選定：各非ルートスイッチのルートブリッジへの最短経路ポート（最小累積コスト）
  3. デジグネイテッドポートの選定：各セグメントでルートブリッジへ最短のポート
  4. ブロッキング：上記以外のポートはブロッキング（フレーム転送停止）

STPポートの状態（Rapid PVST+）

状態 転送 学習 説明
Discarding × × ブロッキング・フレーム転送なし
Learning × ○ MACアドレスを学習中
Forwarding ○ ○ 通常転送状態

STPコスト（リンク速度別）

リンク速度 STPコスト
10Mbps 100
100Mbps 19
1Gbps 4
10Gbps 2

Rapid PVST+設定

Switch(config)# spanning-tree mode rapid-pvst
Switch(config)# spanning-tree vlan 10 priority 4096   # ルートブリッジに設定
Switch(config)# spanning-tree vlan 10 root primary   # 自動でプライオリティ設定

# PortFast（エッジポート向け）
Switch(config-if)# spanning-tree portfast
Switch(config-if)# spanning-tree bpduguard enable

# 確認
Switch# show spanning-tree vlan 10

✏️ 確認問題（第2-4章）

Q1. STPにおいてルートブリッジが選出される基準として正しいのはどれか？
正解：A
ルートブリッジは最小のブリッジIDを持つスイッチが選出されます。ブリッジID=プライオリティ（デフォルト32768）+MACアドレスです。
Q2. 1GbpsリンクのSTPコストはいくつか？
正解：C（4）
STPコスト：10Mbps=100、100Mbps=19、1Gbps=4、10Gbps=2。コストが小さいほど優先されます。

2-5 CDP・LLDP

設定 隣接機器を自動探索するL2探索プロトコル

🔍CDP vs LLDP

項目 CDP LLDP
開発元 Cisco（独自） IEEE 802.1AB（標準）
対応機器 Cisco機器のみ マルチベンダー
デフォルト状態 有効 無効
通知間隔 60秒 30秒
ホールドタイム 180秒 120秒 
# CDP確認コマンド
Switch# show cdp neighbors
Switch# show cdp neighbors detail

# LLDP有効化と確認
Switch(config)# lldp run
Switch# show lldp neighbors

✏️ 確認問題（第2-5章）

Q1. マルチベンダー環境で動作するIEEE標準のL2探索プロトコルはどれか？
正解：B（LLDP）
LLDPはIEEE 802.1ABの標準プロトコルで、異なるベンダーの機器間でも動作します。CDPはCisco独自です。

2-6 Cisco無線LAN (WLC・AP)

概念 CiscoのWLCとAPの管理アーキテクチャを理解する

📡APの動作モード

モード 説明
Autonomous（自律型） APが独立して動作。各APを個別設定
Lightweight（集中管理型） WLC（無線LANコントローラ）が全APを集中管理。CAPWAPで通信
FlexConnect WLCへの接続が切れてもローカルで動作継続可能

CAPWAP（Control And Provisioning of Wireless Access Points）

  • APとWLC間の制御・データ転送に使用するトンネルプロトコル
  • 制御チャネル：UDP 5246（暗号化）
  • データチャネル：UDP 5247（暗号化オプション）

WLC管理アクセス方法

アクセス方法 プロトコル 説明
WebUI HTTP/HTTPS GUIによる設定（最も一般的）
CLI SSH/Telnet コマンドライン設定
コンソール RS-232 初期設定・障害対応時

✏️ 確認問題（第2-6章）

Q1. LightweightモードのAPとWLC間で使用されるトンネルプロトコルはどれか？
正解：B（CAPWAP）
CAPWAPはLightweight APとWLC間の制御・データ通信に使用されます。UDP 5246（制御）とUDP 5247（データ）を使用します。
