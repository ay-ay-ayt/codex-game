3-1 ルーティング基礎・ルーティングテーブル

頻出 ルータの転送判断とルーティングテーブルの読み方を理解する

🗺️ルーティングテーブルの見方

Router# show ip route
Codes: C - connected, S - static, O - OSPF, R - RIP, * - candidate default

     10.0.0.0/8 is variably subnetted, 2 subnets, 2 masks
C       10.1.1.0/24 is directly connected, GigabitEthernet0/0
L       10.1.1.1/32 is directly connected, GigabitEthernet0/0
S    192.168.2.0/24 [1/0] via 10.1.1.2
O    172.16.0.0/16 [110/2] via 10.1.1.2, 00:05:30, GigabitEthernet0/0
S*   0.0.0.0/0 [1/0] via 203.0.113.1

ルーティングテーブルのコード説明

コード 意味 AD値
C Connected（直接接続） 0
L Local（ルータ自身のアドレス） 0
S Static（スタティックルート） 1
O OSPF 110
R RIP 120
D EIGRP 90
S* デフォルトルート（0.0.0.0/0） 1

アドミニストレーティブディスタンス（AD値）

同じ宛先ネットワークへの経路が複数ある場合、AD値が小さいほど優先されます。

🚨 AD値の暗記（頻出）
直接接続(0) ＞ スタティック(1) ＞ EIGRP(90) ＞ OSPF(110) ＞ RIP(120) ＞ 外部EIGRP(170)

ロンゲストマッチ（最長一致）

宛先IPに対して最も長い（詳細な）プレフィックスのルートが選択されます。

例：宛先 192.168.1.100 へのパケット
  ルータに以下のルートがある場合:
  192.168.0.0/16 → が一致
  192.168.1.0/24 → がより詳細に一致 ← こちらが選択される
  192.168.1.96/28 → さらに詳細 ← もしあればこちらが選択

✏️ 確認問題（第3-1章）

Q1. ルーティングテーブルの「O 172.16.0.0/16 [110/2]」の「110」が表すものはどれか？
正解：B（AD値）
[AD値/メトリック]の形式で表記されます。OSPFのAD値は110、この場合のメトリックは2です。
Q2. ルーティングテーブルに複数の経路がある場合、最終的に使用される経路の選択基準で最初に確認されるものはどれか？
正解：A（ロンゲストマッチ）
まずプレフィックス長が最長のルートが選ばれます。同じプレフィックス長が複数あればAD値、さらにメトリックで選択します。

3-2 スタティックルーティング

設定 手動設定するスタティックルートの設定方法をマスターする

✏️スタティックルートの種類

種類 説明 設定例
ネットワークルート 特定のネットワーク宛のルート ip route 192.168.2.0 255.255.255.0 10.1.1.2
ホストルート (/32) 特定の1ホスト宛のルート ip route 192.168.2.100 255.255.255.255 10.1.1.2
デフォルトルート 0.0.0.0/0。一致するルートがない場合に使用 ip route 0.0.0.0 0.0.0.0 203.0.113.1
フローティングスタティック AD値を大きくして通常ルートのバックアップとして使用 ip route 192.168.2.0 255.255.255.0 10.2.2.2 200

スタティックルート設定コマンド

# ネクストホップIPアドレス指定
Router(config)# ip route 192.168.2.0 255.255.255.0 10.1.1.2

# 出口インタフェース指定（P-to-Pリンク向け）
Router(config)# ip route 192.168.2.0 255.255.255.0 GigabitEthernet0/1

# デフォルトルート
Router(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1

# IPv6スタティックルート
Router(config)# ipv6 route 2001:db8:2::/64 2001:db8:1::2
Router(config)# ipv6 route ::/0 2001:db8:1::1  # IPv6デフォルト

# 確認
Router# show ip route static

✏️ 確認問題（第3-2章）

Q1. デフォルトルートの設定として正しいコマンドはどれか？
正解：D
デフォルトルートは「ip route 0.0.0.0 0.0.0.0 ネクストホップ」で設定します。ip default-gatewayはルーティング機能を持たないスイッチで使用します。
Q2. フローティングスタティックルートの目的として正しいのはどれか？
正解：C
フローティングスタティックはAD値を大きく設定して通常は使用されず、メインルートが失われた時のみ有効になるバックアップルートです。

3-3 OSPFv2（シングルエリア）

頻出設定 CCNA最重要トピック。OSPFの動作・設定・確認をマスターする

🔄OSPFの基本

項目 内容
プロトコル リンクステート型プロトコル（アルゴリズム：Dijkstra SPF）
AD値 110
メトリック コスト（= 参照帯域/インタフェース帯域）
参照帯域 デフォルト100Mbps（変更可能）
ハローパケット 10秒（P-to-P）、30秒（NBMA/broadcast）
デッドタイム ハロー間隔×4（デフォルト40秒）
マルチキャスト 224.0.0.5（全OSPFルータ）、224.0.0.6（DR/BDR宛）

OSPFネイバー関係の確立

ネイバー確立の条件（これが一致しないとネイバーにならない！）

  • 同じエリアID
  • 同じサブネット
  • 同じハロー/デッドタイム
  • 同じMTU
  • 認証パスワード（設定している場合）

DR・BDR選出（ブロードキャストネットワーク）

DR/BDRの選出基準（優先順位）

  1. 最大の OSPF プライオリティ（デフォルト1、0にするとDR/BDRにならない）
  2. プライオリティが同じ場合は最大のルータID

ルータIDの決定：①明示的設定 → ②最大のループバックIP → ③最大のアクティブなIPアドレス

OSPFv2の設定

# OSPF有効化
Router(config)# router ospf 1
Router(config-router)# router-id 1.1.1.1
Router(config-router)# network 10.1.1.0 0.0.0.255 area 0
Router(config-router)# network 192.168.1.0 0.0.0.255 area 0
Router(config-router)# passive-interface GigabitEthernet0/1  # エンドユーザー向けIF

# インタフェース単位での設定（代替方法）
Router(config-if)# ip ospf 1 area 0

# コスト調整
Router(config)# router ospf 1
Router(config-router)# auto-cost reference-bandwidth 10000  # 10Gbps基準
Router(config-if)# ip ospf cost 10  # 手動コスト設定

# 確認コマンド（重要！）
Router# show ip ospf neighbor
Router# show ip ospf interface
Router# show ip route ospf
Router# show ip ospf database

✏️ 確認問題（第3-3章）

Q1. OSPFのAD（アドミニストレーティブディスタンス）値はいくつか？
正解：C（110）
OSPFのAD値は110です。EIGRP=90、RIP=120。AD値が小さいほど優先されます。
Q2. OSPFで全OSPFルータ宛のマルチキャストアドレスはどれか？
正解：A（224.0.0.5）
224.0.0.5は全OSPFルータ宛、224.0.0.6はDR/BDR宛のマルチキャストアドレスです。
Q3. OSPFネイバーが確立されない原因として考えられないものはどれか？
正解：B（ルータIDが異なる）
ルータIDは各ルータで固有である必要がありますが（同じIDだとエラー）、ネイバー確立の条件ではありません。異なるルータIDは正常です。

3-4 FHRP（HSRP・VRRP）

概念 デフォルトゲートウェイの冗長化プロトコル

🛡️FHRPとは

FHRP（First Hop Redundancy Protocol）は、エンドホストのデフォルトゲートウェイを冗長化するプロトコルです。仮想IPアドレスと仮想MACアドレスを使い、アクティブルータが障害時に自動で切り替わります。

項目 HSRP VRRP
標準 Cisco独自 IEEE標準（RFC 5798）
アクティブ呼称 Active Master
仮想MAC 0000.0c07.acXX 0000.5e00.01XX
ハロー間隔 3秒 1秒
ホールドタイム 10秒 3秒
プリエンプション デフォルト無効 デフォルト有効

HSRP設定（バージョン2）

Router(config-if)# standby version 2
Router(config-if)# standby 1 ip 192.168.1.254        # 仮想IP
Router(config-if)# standby 1 priority 110           # 優先度（デフォルト100）
Router(config-if)# standby 1 preempt               # プリエンプション有効化
Router# show standby
Router# show standby brief

✏️ 確認問題（第3-4章）

Q1. HSRPはCiscoが開発したFHRPです。IEEEが標準化した同様のプロトコルはどれか？
正解：A（VRRP）
VRRPはIEEE/IETFが標準化（RFC 5798）したFHRPで、マルチベンダー環境でも使用できます。
