2-1 VLAN（Virtual LAN）

頻出設定 VLANの概念・設定・確認を完全マスターする

🏗️VLANとは何か

VLAN（Virtual LAN）は1台の物理スイッチを複数の論理的なネットワーク（ブロードキャストドメイン）に分割する技術です。物理的な配線を変えず論理的にネットワークを分離できます。

VLANなし vs VLANあり の比較

【VLANなし】1つの大きなブロードキャストドメイン
PC-A ──┐
PC-B ──┤── [スイッチ] ← 全PCが同じL2ネットワーク
PC-C ──┤             PC-Aのブロードキャストは全員に届く
PC-D ──┘

【VLANあり】部門ごとに分離したブロードキャストドメイン
PC-A (VLAN10) ──┐
PC-B (VLAN10) ──┤── [スイッチ]  VLAN10:営業部（PC-A,B）
PC-C (VLAN20) ──┤               VLAN20:開発部（PC-C,D）
PC-D (VLAN20) ──┘
→ 営業のブロードキャストは開発部のPCには届かない！

VLANのメリット

メリット 具体的な効果
セキュリティ向上 VLANが異なる端末間は直接通信不可（ルータ経由が必要）
ブロードキャストの削減 各VLANが独立したブロードキャストドメインになる
柔軟なグループ化 物理的な場所に関係なく論理的なグループを作成できる
コスト削減 1台のスイッチで複数ネットワークを実現（機器減少）

🔢VLAN ID の範囲

範囲 VLAN ID 用途
通常VLAN 1〜1005 一般的に使用する範囲。VLANデータベースに保存（vlan.dat）
拡張VLAN 1006〜4094 VTPモードがトランスペアレントまたはVTPv3が必要
予約済み 1006〜1024 Ciscoが内部使用のために予約
VLAN 1 1 デフォルトVLAN。全ポートがデフォルトでVLAN1に属す。削除不可
VLAN 1002〜1005 — Token Ring/FDDIのデフォルトVLAN。現在は使用なし。削除不可

⚙️VLANの設定コマンド（完全版）

VLANの作成

# 方法1: VLANデータベースモードで作成（VLAN設定専用）
Switch# vlan database
Switch(vlan)# vlan 10 name Sales
Switch(vlan)# apply

# 方法2: グローバルコンフィグモードで作成（現代の標準方法）
Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config)# vlan 20
Switch(config-vlan)# name Engineering
Switch(config)# vlan 30
Switch(config-vlan)# name Management

アクセスポート（Access Port）の設定

アクセスポートは1つのVLANのみに属し、エンドデバイス（PC・プリンタ等）を接続するポートです。

Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode access         # アクセスポートに設定
Switch(config-if)# switchport access vlan 10        # VLAN 10に割り当て

# 複数ポートをまとめて設定する場合
Switch(config)# interface range GigabitEthernet0/1 - 5
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10

VLANの確認コマンド

Switch# show vlan brief
VLAN Name                             Status    Ports
---- -------------------------------- --------- -------------------------------
1    default                          active    Gi0/5, Gi0/6, Gi0/7, Gi0/8
10   Sales                            active    Gi0/1, Gi0/2
20   Engineering                      active    Gi0/3, Gi0/4
30   Management                       active
1002 fddi-default                     act/unsup
（以下省略）

Switch# show vlan id 10               # 特定VLANの詳細確認
Switch# show interfaces GigabitEthernet0/1 switchport  # ポートのVLAN設定確認
📌 VLANの保存場所
VLANの設定はvlan.datファイル（フラッシュメモリ）に保存されます。running-configには含まれないため、「copy running-config startup-config」だけではVLAN情報は保存されません。ただし、グローバルコンフィグモードで作成したVLANはrunning-configに含まれます。

🌐VLAN間ルーティング

異なるVLAN間の通信にはL3デバイス（ルータまたはL3スイッチ）が必要です。

方式 仕組み 特徴
Router-on-a-Stick（ROAS） 1本のトランクリンクでルータとスイッチを接続。ルータ上にサブインタフェースを作成 シンプルだがトランクリンクがボトルネックになりやすい
L3スイッチのSVI L3スイッチ上にVLAN仮想インタフェース（SVI）を作成してルーティング 高速・標準構成。「ip routing」を有効化する 
▼ Router-on-a-Stick の設定例
Router(config)# interface GigabitEthernet0/0.10     # VLAN10用サブIF
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config)# interface GigabitEthernet0/0.20     # VLAN20用サブIF
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0

▼ L3スイッチのSVI設定例
L3Switch(config)# ip routing                           # ルーティング有効化
L3Switch(config)# interface Vlan10
L3Switch(config-if)# ip address 192.168.10.1 255.255.255.0
L3Switch(config-if)# no shutdown
L3Switch(config)# interface Vlan20
L3Switch(config-if)# ip address 192.168.20.1 255.255.255.0
L3Switch(config-if)# no shutdown

✏️ 確認問題（第2-1章）

Q1. VLANを使うことで分割できるのは何か？
正解：B（ブロードキャストドメイン）
VLANは1台のスイッチを複数のブロードキャストドメインに分割します。コリジョンドメインはスイッチ（L2）の各ポートで既に分割されています。
Q2. Ciscoスイッチで全ポートがデフォルトで所属するVLANはどれか？
正解：C（VLAN 1）
Ciscoスイッチの全ポートはデフォルトでVLAN 1に属します。VLAN 1はデフォルトVLANで削除できません。セキュリティ上、VLAN 1をユーザーポートに使うのは推奨されません。
Q3. 異なるVLAN間で通信するために必要なのはどれか？
正解：D
VLANは異なるブロードキャストドメインなので、同士間の通信にはL3（ルータまたはL3スイッチ）によるルーティングが必要です。L2スイッチだけでは異VLAN通信は不可能です。
Q4. ポートをVLAN 10のアクセスポートに設定するコマンドとして正しいのはどれか？
正解：A
アクセスポート設定は「switchport mode access」でアクセスモードにし、「switchport access vlan 10」でVLANを指定します。この2コマンドがセットです。
Q5. Router-on-a-Stick（ROAS）方式でVLAN間ルーティングを実現する場合、ルータ側で作成するものはどれか？
正解：C（サブインタフェース）
ROASではルータの物理インタフェースにサブインタフェース（例: Gi0/0.10 Gi0/0.20）を作成し、各々に「encapsulation dot1Q VLAN-ID」を設定します。SVIはL3スイッチのVLAN間ルーティング方法です。

2-2 トランクポート・802.1Q・VTP

頻出設定 トランクの仕組みと設定・VTP の動作を理解する

🔗トランクポートとは

トランクポートは複数のVLANのトラフィックを1本のリンクで伝送するためのポートです。スイッチ間やスイッチとルータ間（ROAS）の接続に使います。

アクセスポート vs トランクポートの違い

アクセスポート（Access Port）
  ・1つのVLANのみ通す
  ・フレームにVLANタグを「付けない」
  ・エンドデバイス（PC・IP電話等）接続に使う

トランクポート（Trunk Port）
  ・複数VLANのトラフィックを通す
  ・フレームにVLANタグを「付ける」（IEEE 802.1Q）
  ・スイッチ間・スイッチ〜ルータ間に使う

🏷️IEEE 802.1Q タギング

802.1Q（dot1Q）はVLAN IDをEthernetフレームに埋め込む業界標準規格です。

802.1QタグをEthernetフレームに挿入する位置

【通常の Ethernet II フレーム】
┌─────────────┬─────────────┬────────┬──────────┬─────┐
│ 宛先MAC(6B) │ 送信元MAC(6B)│Type(2B)│ データ   │ FCS │
└─────────────┴─────────────┴────────┴──────────┴─────┘

【802.1Q タグ付きフレーム（送信元MACの直後に挿入）】
┌─────────────┬─────────────┬────────────────┬────────┬──────────┬─────┐
│ 宛先MAC(6B) │ 送信元MAC(6B)│802.1Qタグ(4B)  │Type(2B)│ データ   │ FCS │
└─────────────┴─────────────┴────────────────┴────────┴──────────┴─────┘

802.1Qタグ（4バイト）の内容:
┌──────────────────┬───┬────────────────────┐
│ TPID: 0x8100(2B) │PCP│  VLAN ID: 1〜4094   │
│（タグ付きと識別） │(3)│  (12ビット)         │
└──────────────────┴───┴────────────────────┘

ネイティブVLAN（重要）

  • ネイティブVLANのトラフィックはトランクリンクでタグなしで送受信される
  • Ciscoのデフォルトネイティブ VLAN はVLAN 1
  • トランクリンクの両端でネイティブVLANが一致していないと通信障害が発生
  • セキュリティ上、ネイティブVLANはユーザーが使わないVLAN（例:VLAN999）に変更を推奨

⚙️トランクポート設定コマンド

# スイッチ間のトランクポート設定
Switch(config)# interface GigabitEthernet0/24
Switch(config-if)# switchport mode trunk                   # トランクに固定
Switch(config-if)# switchport trunk encapsulation dot1q    # 802.1Q（一部の機種で必要）
Switch(config-if)# switchport trunk native vlan 999         # ネイティブVLANを変更

# 通過を許可するVLANを制限（セキュリティ向上・帯域節約）
Switch(config-if)# switchport trunk allowed vlan 10,20,30    # VLAN10,20,30のみ許可
Switch(config-if)# switchport trunk allowed vlan add 40       # VLAN40を追加
Switch(config-if)# switchport trunk allowed vlan remove 30    # VLAN30を除外

# トランク確認コマンド
Switch# show interfaces trunk
Port        Mode             Encapsulation  Status        Native vlan
Gi0/24      on               802.1q         trunking      999

Port        Vlans allowed on trunk
Gi0/24      10,20,30

Port        Vlans allowed and active in management domain
Gi0/24      10,20,30

Port        Vlans in spanning tree forwarding state and not pruned
Gi0/24      10,20,30

🔄DTPとトランク交渉

DTP（Dynamic Trunking Protocol）はCisco独自のトランク自動交渉プロトコルです。

モード コマンド 動作 相手がautoの場合 相手がonの場合
access switchport mode access 常にアクセスポート アクセス アクセス（不一致）
trunk switchport mode trunk 常にトランクポート トランク トランク
dynamic desirable switchport mode dynamic desirable 積極的にトランク交渉 トランク トランク
dynamic auto switchport mode dynamic auto 受動的に交渉（デフォルト） アクセス トランク
DTP無効 switchport nonegotiate DTPフレームを送らない — —
🚨 試験ポイント：autoとautoの組み合わせはトランクにならない
dynamic auto + dynamic auto = アクセスポートになる（どちらも受動的なので交渉が進まない）
セキュリティのベストプラクティス: スイッチポートは明示的に access または trunk に固定し、「switchport nonegotiate」でDTPを無効化する。

📡VTP（VLAN Trunking Protocol）

VTPはCisco独自のVLAN情報を複数スイッチ間で同期するプロトコルです。

VTPモード VLAN追加/削除 VTP情報の転送 VTP情報の保存
Server 可能 転送する 保存する
Client 不可 転送する 保存しない
Transparent 可能（ローカルのみ） 転送するが適用しない 保存する（ローカル）
Off（VTPv3） 可能（ローカルのみ） 転送しない 保存する
⚠️ VTPのリスク（VTPリビジョン番号問題）
既存ネットワークに高いリビジョン番号を持つスイッチを追加すると、そのスイッチのVLAN情報が全域に伝播し既存のVLANが削除される危険があります。このためVTPは慎重に使用するか、Transparentモードを推奨します。

✏️ 確認問題（第2-2章）

Q1. 802.1QタグがEthernetフレームのどの位置に追加されるか？
正解：A
802.1Qタグは送信元MACアドレスとEtherTypeの間（送信元MACの直後）に4バイト挿入されます。タグにはTPID(0x8100)・PCP・VID（VLAN ID）が含まれます。
Q2. CiscoスイッチのトランクポートのデフォルトのネイティブVLANはどれか？
正解：C（VLAN 1）
デフォルトネイティブVLANはVLAN 1です。ネイティブVLANのトラフィックはタグなしで送信されるため、両端のスイッチでネイティブVLANが一致しないとネイティブVLANミスマッチエラーが発生します。
Q3. DTPで「dynamic auto」同士（両方のポートが dynamic auto）を接続した場合の結果はどれか？
正解：D（アクセスポート）
dynamic auto同士はどちらも「相手がdesirable/trunkになるのを待つ」受動的なモードのため、トランク交渉が進まずアクセスポートになります。
Q4. VTPでVLAN情報をVTPの同期を受け入れるが、自身ではVLANを追加・削除できないモードはどれか？
正解：B（Client）
VTP Clientモードはサーバーからのアップデートを受け入れてVLAN情報を適用しますが、自分ではVLANを追加・削除できません。Transparentはローカルで自由に変更可能ですがVTP情報を転送するだけです（適用しない）。
