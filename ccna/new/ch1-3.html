1-3 IPv4アドレス・サブネット計算

頻出計算 サブネット計算は確実に解けるようにする。試験で必ず出る。

🔢IPv4アドレスの基礎

IPv4アドレスは32ビット（4オクテット）の数値で、8ビットずつをドット区切りの10進数で表します。

2進数と10進数の変換（8ビット）

ビット位置:  2⁷   2⁶   2⁵   2⁴   2³   2²   2¹   2⁰
値:         128   64   32   16    8    4    2    1
           ────────────────────────────────────────
例: 192  =   1    1    0    0    0    0    0    0  → 11000000
例: 168  =   1    0    1    0    1    0    0    0  → 10101000
例: 1    =   0    0    0    0    0    0    0    1  → 00000001
例: 255  =   1    1    1    1    1    1    1    1  → 11111111

→ 192.168.1.0 = 11000000.10101000.00000001.00000000

IPアドレスのクラス分類

クラス 先頭ビット 範囲 デフォルトマスク ホスト数 用途
A 0xxx 1.0.0.0 〜 126.255.255.255 /8 (255.0.0.0) 約1677万 超大規模ネットワーク
B 10xx 128.0.0.0 〜 191.255.255.255 /16 (255.255.0.0) 約65534 大規模ネットワーク
C 110x 192.0.0.0 〜 223.255.255.255 /24 (255.255.255.0) 254 小規模ネットワーク
D 1110 224.0.0.0 〜 239.255.255.255 — — マルチキャスト
E 1111 240.0.0.0 〜 255.255.255.255 — — 実験用（予約済み）
📌 127.x.x.x はループバックアドレス（クラスAに含まれるが特別扱い）
127.0.0.1はローカルホスト（自分自身）を指します。「自分のTCP/IPスタックが正常に機能しているか」の確認に使います（pingで確認可能）。

プライベートIPアドレス（RFC 1918）

クラス プライベートアドレス範囲 CIDR表記
A 10.0.0.0 〜 10.255.255.255 10.0.0.0/8
B 172.16.0.0 〜 172.31.255.255 172.16.0.0/12
C 192.168.0.0 〜 192.168.255.255 192.168.0.0/16

プライベートIPアドレスはインターネット上でルーティングされません。NATを使ってグローバルIPに変換してからインターネットに出ます。

🧮サブネット計算（最重要）

サブネットマスクの基礎

サブネットマスクはIPアドレスのどの部分がネットワーク部でどの部分がホスト部かを示します。

プレフィックス   サブネットマスク         ホストビット数   使用可能ホスト数
/24           255.255.255.0          8ビット         2⁸ - 2 = 254台
/25           255.255.255.128        7ビット         2⁷ - 2 = 126台
/26           255.255.255.192        6ビット         2⁶ - 2 = 62台
/27           255.255.255.224        5ビット         2⁵ - 2 = 30台
/28           255.255.255.240        4ビット         2⁴ - 2 = 14台
/29           255.255.255.248        3ビット         2³ - 2 = 6台
/30           255.255.255.252        2ビット         2² - 2 = 2台（P-to-Pリンク用）
/32           255.255.255.255        0ビット         1台（ループバック等）

公式: 使用可能ホスト数 = 2^(ホストビット数) - 2
（-2はネットワークアドレスとブロードキャストアドレスを除くため）

サブネット計算の手順（例題）

問題: 192.168.10.100/26 のネットワーク情報を全て求めよ

【ステップ1】プレフィックス /26 から情報を読み取る
  ネットワークビット: 26ビット
  ホストビット:      32 - 26 = 6ビット
  ブロックサイズ:    2⁶ = 64

【ステップ2】ネットワークアドレスを求める
  第4オクテット 100 を64で割る → 100 ÷ 64 = 1 余り 36
  → ネットワークアドレスの第4オクテット = 1 × 64 = 64
  → ネットワークアドレス: 192.168.10.64

【ステップ3】各アドレスを計算する
  ネットワークアドレス:    192.168.10.64   ← ホスト割り当て不可
  最初の使用可能ホスト:    192.168.10.65
  最後の使用可能ホスト:    192.168.10.126
  ブロードキャストアドレス: 192.168.10.127  ← ホスト割り当て不可
  サブネットマスク:        255.255.255.192
  次のネットワーク:        192.168.10.128

【ステップ4】使用可能ホスト数
  2⁶ - 2 = 62台

ブロックサイズ早見表（/24〜/30）

CIDR マスク(第4oct) ブロックサイズ サブネット数(/24から) 使用可能ホスト数
/24 0 256 1 254
/25 128 128 2 126
/26 192 64 4 62
/27 224 32 8 30
/28 240 16 16 14
/29 248 8 32 6
/30 252 4 64 2

VLSM（可変長サブネットマスク）

VLSMは同一ネットワーク内で複数の異なるサブネットマスクを使う技術です。アドレス空間を効率よく使えます。

VLSMの例題

192.168.1.0/24 を以下の要件に分割する：
  ・部署A: 50台必要 → /26 (62ホスト) → 192.168.1.0/26  (〜.63)
  ・部署B: 25台必要 → /27 (30ホスト) → 192.168.1.64/27 (〜.95)
  ・部署C: 10台必要 → /28 (14ホスト) → 192.168.1.96/28 (〜.111)
  ・P-to-Pリンク   → /30 (2ホスト)  → 192.168.1.112/30(〜.115)

大きいサブネットから割り当てるのがVLSMのルール！

✏️ 確認問題（第1-3章）

Q1. 172.16.50.200/20 のネットワークアドレスはどれか？
正解：B（172.16.48.0）
/20はネットワークビット20bit、ホストビット12bit。第3オクテットに影響あり。マスクの第3oct = 256-(2^(24-20))= 256-16=240。50÷16=3余り2 → 3×16=48。→ ネットワークアドレス: 172.16.48.0
Q2. /29 のサブネットで使用可能なホスト数はいくつか？
正解：C（6台）
/29のホストビット = 32-29 = 3ビット。使用可能ホスト数 = 2³ - 2 = 8 - 2 = 6台。-2はネットワークアドレスとブロードキャストを除くため。
Q3. 192.168.1.200/27 のブロードキャストアドレスはどれか？
正解：D（192.168.1.223）
/27のブロックサイズ=32。200÷32=6余り8 → ネットワークアドレス=6×32=192。次のネットワーク=192+32=224。ブロードキャスト=224-1=223。→ 192.168.1.223
Q4. P-to-P（ポイントツーポイント）リンクに最適なサブネットはどれか？
正解：A（/30）
ルータ間のP-to-Pリンクは2台分のIPアドレスだけが必要です。/30はホストビット2bitで使用可能ホスト=2台（ちょうど）。アドレス無駄なく使えます。/31は特殊（RFC 3021）で、/32は1ホストのみです。
Q5. プライベートIPアドレス範囲として正しいものはどれか？
正解：C
RFC 1918プライベートアドレス: 10.0.0.0/8（10.x.x.x すべて）、172.16.0.0/12（172.16〜172.31.x.x）、192.168.0.0/16（192.168.x.x すべて）。
Q6. 10.0.0.0/8 のサブネットでホスト数を最大にするために使えるマスクはどれか？
正解：B（/9）
ホストビット数が多いほどホスト数が多くなります。/9はホストビット=23bit=8,388,606台。/8から分割する場合に最大ホスト数を確保するには最小のサブネットビット追加（/8+1=/9）にします。
Q7. 192.168.5.0/24 を /26 に分割した場合、何個のサブネットができるか？
正解：D（4個）
/24→/26に変更するとサブネットビットが2bit追加されます。2²=4個のサブネットが生成されます。各サブネットのブロックサイズは64、ホスト数は62台。
