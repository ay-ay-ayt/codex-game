📋第4章範囲（IPサービス）Q28-Q36

Q28. PATの最大の特徴はどれか？
正解：C
PAT(NAT Overload)は送信元ポート番号を使い分けることで、1つのグローバルIPを多数のホストで共有します。Aはスタティック/ダイナミックNAT。
Q29.【show出力問題】以下のshow ip nat translationsの出力から正しく読み取れることはどれか？
Pro Inside global Inside local Outside local Outside global
tcp 203.0.113.1:1024 192.168.1.10:5000 93.184.216.34:80 93.184.216.34:80
正解：B
Inside local(内部実IP)=192.168.1.10。Inside global(NATで変換後のIP:ポート)=203.0.113.1:1024。Outside(外部サーバー)=93.184.216.34:80(HTTP)。ポート番号変換=PAT。
Q30. DHCPの4ステップ(DORA)の正しい順序はどれか？
正解：A（DORA）
D=クライアントがブロードキャストで探索→O=サーバーがIP提案→R=クライアントが選択→A=サーバーが確認・割り当て。
Q31. Syslogのセキュリティレベルで「Emergency(0)」より1段階低い(次に重要な)レベルはどれか？
正解：D（Alert=1）
Syslog: 0=Emergency, 1=Alert, 2=Critical, 3=Error, 4=Warning, 5=Notification, 6=Informational, 7=Debugging。数字が小さいほど深刻。
Q32. NTPのStratum値について正しいのはどれか？
正解：C
Stratum 0=原子時計等（直接NTP不参加）。Stratum 1=Stratum 0に直結したサーバー。Stratum値が大きい=参照元から遠い=精度が落ちる。範囲は0〜15(16は同期不能)。
Q33. SNMPv3の特徴として正しいのはどれか？
正解：B
SNMPv3: authNoPriv(認証あり・暗号化なし)、authPriv(認証+暗号化)のセキュリティレベルをサポート。v1/v2cはコミュニティストリング（平文）で認証するため非推奨。
Q34. QoSのマーキングで、DSCP値「EF」が使用されるトラフィックタイプはどれか？
正解：A
EF(Expedited Forwarding)=DSCP 46=音声トラフィック用（低遅延・低ジッター保証）。AF=保証転送。BE(Best Effort)=一般トラフィック。
Q35. DHCPリレーエージェント(ip helper-address)が必要になるのはどのような場合か？
正解：D
DHCP Discoverはブロードキャストでルータを越えられません。ip helper-addressでルータがDHCPサーバーにユニキャスト転送します。
Q36. SSHの設定で必要なコマンドのうち、正しくないのはどれか？
正解：C（正しくない）
SSHを使うにはtransport input sshを設定します。transport input telnetだとTelnet(平文)のみを許可してしまい、SSHが使えません。

📋第5章範囲（セキュリティ）Q37-Q44

Q37. 標準ACLと拡張ACLの違いとして正しいのはどれか？
正解：B
標準ACL(1-99,1300-1999)=送信元IPのみ。拡張ACL(100-199,2000-2699)=送信元/宛先IP+プロトコル+ポート番号。
Q38. ACLの適用場所のベストプラクティスとして正しいのはどれか？
正解：A
拡張ACLは細かく(宛先も)フィルタできるため送信元に近い場所で不要トラフィックを早期にブロック。標準ACLは送信元IPのみなので宛先に近い場所で適用し、意図しないトラフィック遮断を防ぎます。
Q39. DHCPスヌーピングで「信頼されないポート」(untrusted)から受信した場合にドロップされるメッセージはどれか？
正解：D
untrustedポートからのDHCP Offer/ACKはドロップされます（不正DHCPサーバー対策）。クライアント側メッセージ(Discover/Request)はuntrustedポートから送信可能です。
Q40. ポートセキュリティのviolationモードで、違反時にポートをerr-disabledにするのはどれか？
正解：C（shutdown）
shutdown=err-disabled(ポート無効化)+syslog+カウンタ増加。restrict=パケット破棄+syslog+カウンタ。protect=パケット破棄のみ。
Q41.【シナリオ】MACフラッディング攻撃を受けてスイッチのCAMテーブルが溢れた場合、スイッチはどのような動作をするか？
正解：B
CAMテーブルが満杯になると新しいMACを学習できず、未知のMACアドレス宛のフレームを全ポートにフラッディングします。攻撃者はこれを利用して他のポートのトラフィックを盗聴できます。
Q42. Site-to-Site VPNとRemote Access VPNの違いとして正しいのはどれか？
正解：A
Site-to-Site=拠点間のゲートウェイ接続(IPsec)。Remote Access=VPNC(Cisco AnyConnect等)で個人端末から接続(SSL/IPsec)。
Q43. 802.1X認証の3つのコンポーネントで正しい組み合わせはどれか？
正解：D
802.1X: サプリカント=認証を要求するクライアント。オーセンティケータ=スイッチやAPで認証を仲介。認証サーバー=RADIUSで実際の認証判定。
Q44. IPsecのESP(Encapsulating Security Payload)が提供する機能はどれか？（2つ選べ）
正解：B
ESP=暗号化+認証+完全性。AH=認証+完全性のみ（暗号化なし）。ESPはIPプロトコル番号50を使用します。

📋第6章範囲（自動化と可搬性）Q45-Q50

Q45. SDNアーキテクチャでNorthbound APIの役割はどれか？
正解：C
Northbound API=上(アプリ)→コントローラ。Southbound API=コントローラ→下(機器)。REST APIがNorthboundで多用されます。
Q46. REST APIでリソースを部分的に更新するHTTPメソッドはどれか？
正解：A（PATCH）
PATCH=部分更新。PUT=全体更新（置換）。POST=新規作成。GET=読み取り。DELETE=削除。
Q47. 以下のデータ形式を見て正しく識別せよ：
hostname:
  name: R1
  interfaces:
    - GigabitEthernet0/0
    - GigabitEthernet0/1
正解：D（YAML）
インデントで構造を表現、クォーテーション不要、 - でリスト項目を表すのがYAMLの特徴。JSON=波括弧{}と角括弧[]。XML=タグ<>。
Q48. Ansibleの特徴として正しいのはどれか？（2つ選べ）
正解：B
Ansible: エージェントレス+SSH+YAML(Playbook)+プッシュ型。Puppet: エージェント必要+プル型+独自DSL(Manifest)。Chef: エージェント必要+プル型+Ruby(Recipe)。
Q49. NETCONFプロトコルが使用するトランスポートとデータ形式の正しい組み合わせはどれか？
正解：A
NETCONF=SSH(TCP/830)+XML。RESTCONF=HTTPS+JSON or XML。NETCONFはedit-config等のRPC操作でネットワーク機器を設定します。
Q50.【シナリオ】企業で1000台のスイッチのVLAN設定を一括変更したい。最も効率的な方法はどれか？
正解：C
Ansibleは冪等性を持つPlaybookで1000台に同時にSSH接続して設定変更可能。DNA Centerはitent-based(意図ベース)で設定を自動生成・適用。手動CLIは非現実的です。
