3-1 ルーティング基礎・ルーティングテーブル

頻出 ルーティングの仕組み・テーブルの読み方・AD値を完全理解する

🗺️ルーティングとは

ルーティングはルータが宛先IPアドレスに基づいてパケットを最適なインタフェースへ転送するプロセスです。ルータはルーティングテーブルを参照して転送先を決定します。

パケット転送の流れ

① パケット受信
② 宛先IPアドレスを確認
③ ルーティングテーブルを検索
   ・最もプレフィックス長が長い（最長プレフィックスマッチ）経路を選択
   ・一致なし → デフォルトルート（0.0.0.0/0）を確認
   ・デフォルトルートもなし → パケット廃棄（ICMPでDest Unreachable返送）
④ 次ホップ（Next-hop）または出力インタフェースへ転送
⑤ 出力インタフェースでL2ヘッダを書き換えて送信
   （送信元MAC = 自分のIF MAC、宛先MAC = 次ホップのMAC or ゲートウェイMAC）

📋ルーティングテーブルの読み方

Router# show ip route
Codes: L - local, C - connected, S - static, R - RIP, M - mobile, B - BGP
       D - EIGRP, EX - EIGRP external, O - OSPF, IA - OSPF inter area
       i - IS-IS, su - IS-IS summary, * - candidate default

Gateway of last resort is 203.0.113.1 to network 0.0.0.0

ルーティングテーブルエントリの見方

O    10.0.0.0/8 [110/20] via 192.168.1.2, 00:05:12, GigabitEthernet0/0
│    │          │   │    │               │           │
│    │          │   │    │               │           └─ 出力インタフェース
│    │          │   │    │               └─ 経路が追加されてからの時間
│    │          │   │    └─ 次ホップIPアドレス
│    │          │   └─ メトリック（経路コスト。OSPFはコスト値）
│    │          └─ AD値（Administrative Distance = 110 = OSPF）
│    └─ 宛先ネットワーク/プレフィックス長
└─ ルートのソース（O = OSPF）

⚖️AD値（Administrative Distance）

複数のルーティングソースから同じネットワークへの経路がある場合、AD値が小さいほど優先されます。

ルートソース AD値
直接接続（Connected） 0
スタティックルート 1
EIGRP（集約） 5
BGP（外部） 20
EIGRP（内部） 90
OSPF 110
IS-IS 115
RIP 120
EIGRP（外部） 170
BGP（内部） 200
到達不能 255
🚨 AD値は必須暗記（特にConnected=0、Static=1、OSPF=110、RIP=120）
同じ宛先への経路がスタティック（AD=1）とOSPF（AD=110）で競合している場合、AD値が小さいスタティックルートが優先されます。

🔢最長プレフィックスマッチ（Longest Prefix Match）

どの経路が選択されるか？

ルーティングテーブルに以下が存在する場合：
  10.0.0.0/8       → インタフェースA
  10.1.0.0/16      → インタフェースB
  10.1.1.0/24      → インタフェースC
  0.0.0.0/0        → インタフェースD（デフォルト）

宛先 10.1.1.5 へのパケットはどこへ転送？
  10.0.0.0/8:   一致（マスク8bit）
  10.1.0.0/16:  一致（マスク16bit）
  10.1.1.0/24:  一致（マスク24bit）← 最も長い → 優先！

結果: インタフェースC へ転送（最長プレフィックスが勝つ）

📌直接接続ルートとローカルルート

コード 意味 プレフィックス長
C（Connected） 直接接続ネットワーク（サブネット全体） 設定したサブネットのプレフィックス（例:/24）
L（Local） インタフェース自身のIPアドレス /32（ホストルート）

インタフェースにIPアドレスを設定するとCとLの2つのルートが自動的に追加されます。これらはno shutdownになっていることが条件です。

✏️ 確認問題（第3-1章）

Q1. ルーティングテーブルに存在する複数の経路から最適経路を選択する際に最初に参照されるのはどれか？
正解：C（最長プレフィックスマッチ）
最初にプレフィックス長が最も長い（最も具体的な）経路が選ばれます。プレフィックス長が同じ場合はAD値、さらに同じ場合はメトリックで比較します。
Q2. OSPFのデフォルトのAD値はどれか？
正解：B（110）
OSPFのAD値は110。EIGRP内部=90、RIP=120、スタティック=1。AD値が小さいほど信頼性が高く優先されます。
Q3. show ip routeコマンドで宛先ネットワークの隣に表示される「[110/20]」の意味として正しいのはどれか？
正解：A
[AD値/メトリック]の順に表示されます。[110/20]であれば、AD値=110（OSPF）、メトリック（OSPFコスト）=20を意味します。

3-2 スタティックルーティング

頻出設定 スタティックルートの設定・種類・フローティングスタティックルートをマスター

📍スタティックルートとは

管理者が手動で設定する静的な経路情報です。動的ルーティングプロトコルのオーバーヘッドがなく、小規模ネットワークや特定の経路制御に使われます。

比較項目 スタティックルーティング ダイナミックルーティング
設定 手動（管理者が入力） 自動（プロトコルで学習）
障害対応 手動変更が必要 自動的に再計算して迂回
CPUオーバーヘッド 非常に低い 高い（定期的に計算）
帯域幅使用 なし あり（ルーティングアップデート送信）
スケーラビリティ 低い（規模が大きくなると管理困難） 高い
セキュリティ 高い（プロトコルの脆弱性なし） 比較的低い
AD値 1 プロトコルによる（90〜120等）

⚙️スタティックルートの設定

# 基本構文: ip route [宛先ネットワーク] [サブネットマスク] [次ホップIPまたは出力IF]

# 方法1: 次ホップIPアドレスを指定（推奨）
Router(config)# ip route 10.1.1.0 255.255.255.0 192.168.1.2

# 方法2: 出力インタフェースを指定（シリアル等のP-to-Pで使用）
Router(config)# ip route 10.1.1.0 255.255.255.0 GigabitEthernet0/1

# 方法3: 次ホップIPとインタフェースの両方を指定（Ethernetで推奨）
Router(config)# ip route 10.1.1.0 255.255.255.0 GigabitEthernet0/1 192.168.1.2

# デフォルトルート（全ての宛先への経路）
Router(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1    # ISPゲートウェイへ

# スタティックルートの確認
Router# show ip route static
Router# show ip route

🛡️フローティングスタティックルート

フローティングスタティックルートは通常のルートのバックアップとして機能する静的経路です。AD値を大きくすることで、プライマリ経路が消えた場合にのみ有効になります。

フローティングスタティックの設定例

構成:
R1 ─── プライマリ（OSPF経由）─── R2 ─── 10.1.1.0/24
  └─── バックアップ（スタティック）────────┘

プライマリ経由: OSPFで学習 AD=110
バックアップ: スタティックルートをAD=210に設定

通常時: OSPFルート（AD=110）が有効
障害時: OSPFルートが消えるとAD=210のスタティックが有効（フローティング）

# フローティングスタティックルート（AD値を手動で指定）
Router(config)# ip route 10.1.1.0 255.255.255.0 192.168.2.1 210
# ↑ 末尾の210がAD値（OSPFの110より大きい値に設定）

🌐IPv6スタティックルート

# IPv6スタティックルートの設定（ipv6 route コマンド）
Router(config)# ipv6 route 2001:db8:2::/64 2001:db8:1::2

# IPv6デフォルトルート
Router(config)# ipv6 route ::/0 2001:db8:1::1

# リンクローカルを次ホップにする場合は出力IFも指定が必要
Router(config)# ipv6 route 2001:db8:2::/64 GigabitEthernet0/0 fe80::2

✏️ 確認問題（第3-2章）

Q1. フローティングスタティックルートの説明として正しいのはどれか？
正解：C
フローティングスタティックルートはAD値を大きく設定（例:210）することで、プライマリ経路（例:OSPFのAD=110）が有効な間はルーティングテーブルに表示されず（浮いている=floating）、プライマリ障害時のみ有効になる静的経路です。
Q2. デフォルトルートをスタティックで設定するコマンドはどれか？
正解：A
デフォルトルートは宛先100.0.0.0 0.0.0.0（全ビット0のネットワーク/マスク）で設定します。これは「任意の宛先」を意味し、他のどの経路にも一致しないパケットがここへ転送されます。
Q3. イーサネットインタフェース経由でスタティックルートを設定する時の推奨方法はどれか？
正解：D
Ethernetインタフェース（マルチアクセスメディア）で出力IFのみ指定すると、ARPを複数回発生させてしまいます。次ホップIPのみ、または出力IF+次ホップIPの組み合わせが推奨されます。P-to-Pのシリアル回線では出力IFのみ指定でもOKです。
