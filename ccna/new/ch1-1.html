1-1 ネットワーク概要・機器の役割

頻出 ネットワーク機器の違いと役割を完全に理解する

🌐ネットワークとは

ネットワークとは、複数のコンピューターや機器をケーブルや無線で接続し、データを送受信できるようにした仕組みです。インターネット、企業のオフィスLAN、家庭のWi-Fiなどがすべてネットワークです。

ネットワークの分類

種類 正式名称 範囲 例
PAN Personal Area Network 数m（個人周辺） Bluetooth、USB
LAN Local Area Network 建物・フロア内 オフィスのEthernet、Wi-Fi
MAN Metropolitan Area Network 都市圏 市内の光ファイバー網
WAN Wide Area Network 国・大陸をまたぐ インターネット、MPLS専用線

🏗️ネットワークトポロジ

トポロジとは、ネットワーク機器の接続形態です。物理トポロジ（実際のケーブル接続）と論理トポロジ（データの流れ）があります。

トポロジ 構成イメージ 特徴・用途
バス型 全機器が1本のケーブルに接続 古いEthernet（10BASE-5）。障害に弱い
スター型 中央のスイッチに全機器が接続 現代のLANの標準。管理が容易。最も一般的
リング型 機器が環状に接続 Token Ring（現在はほぼ使用なし）
メッシュ型 機器間が多数の経路で接続 冗長性が高い。WANやコアネットワークで使用
スパイン・リーフ型 スパイン（コア）とリーフ（アクセス）の2層 データセンターの標準トポロジ。全リーフが全スパインに接続

スター型トポロジの図（現代LAN）

        [PC-A]   [PC-B]   [PC-C]
           \       |       /
            \      |      /
         [スイッチ（L2）]
                  |
             [ルータ]
                  |
            [インターネット]

全てのPCはスイッチに直接接続。スイッチはルータを通じてインターネットへ接続する構成が最も一般的です。

🖥️主要ネットワーク機器とOSI参照モデル層

ハブ（Hub）— L1（物理層）

  • 受信した信号を全ポートへ無条件に送信（ブロードキャスト的な動作）
  • コリジョンドメインを分割しない → 同時送信で衝突（コリジョン）が発生
  • 半二重通信のみ対応（送信と受信を同時にできない）
  • 現在はほぼ使用されていない（スイッチに置き換わった）

スイッチ（Switch）— L2（データリンク層）

  • MACアドレスを基にフレームを転送する
  • MACアドレステーブル（CAMテーブル）で学習・転送を行う
  • コリジョンドメインを各ポートで分割する（ハブとの最大の違い）
  • 全二重通信に対応（送受信を同時に行える）
  • ブロードキャストドメインは分割しない（VLANで分割が可能）

ルータ（Router）— L3（ネットワーク層）

  • IPアドレスを基にパケットを転送（ルーティング）する
  • 異なるネットワーク（サブネット）間を接続する
  • ブロードキャストドメインを分割する（スイッチとの最大の違い）
  • ルーティングテーブルを使って最適な経路を選択する
  • WAN接続・インターネット接続の境界点となる

L3スイッチ（Layer 3 Switch）

  • スイッチにルーティング機能を追加した機器
  • VLAN間のルーティングをハードウェアで高速に処理する
  • 企業のコア・ディストリビューション層に使用される
  • スタティックルートおよびOSPF等の動的ルーティングが可能

その他の主要機器

機器 L層 役割・特徴
ファイアウォール L3〜L7 セキュリティポリシーに基づきトラフィックを許可/拒否。ACLより高度なステートフル検査
IDS（侵入検知） L3〜L7 不正な通信を検知してアラートを送信。通信は止めない（受動的）
IPS（侵入防止） L3〜L7 不正な通信を検知してリアルタイムでブロック（能動的）
AP（アクセスポイント） L2 無線クライアントを有線LANに接続する。802.11規格
WLC（無線LANコントローラ） L3 複数のAP（Lightweight AP）を一元管理する
DNS サーバー L7 ドメイン名をIPアドレスに解決する
DHCP サーバー L7 クライアントにIPアドレスを自動割り当てする

⚖️スイッチ vs ルータ — 重要比較

比較項目 スイッチ（L2） ルータ（L3）
動作層 L2（データリンク層） L3（ネットワーク層）
識別子 MACアドレス IPアドレス
PDU フレーム（Frame） パケット（Packet）
コリジョンドメイン 各ポートで分割 ○ 各インタフェースで分割 ○
ブロードキャストドメイン 分割しない ✗（VLANで可能） 各インタフェースで分割 ○
異なるネットワーク間通信 不可（同一L2ネットワークのみ） 可能（経路選択）
🚨 試験最頻出ポイント
  • ブロードキャストドメインを分割するのはルータ（またはL3スイッチのVLAN間ルーティング）
  • コリジョンドメインを分割するのはスイッチ（ハブは分割しない）
  • スイッチはMACアドレスで転送、ルータはIPアドレスで転送

🏢3層ネットワーク設計（シスコ階層モデル）

3層モデルの構成

┌─────────────────────────────────────────┐
│  コア層（Core Layer）                    │
│  ・高速なバックボーン（転送に特化）       │
│  ・L3スイッチ/ルータ使用                 │
│  ・セキュリティチェック等は行わない       │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│  ディストリビューション層（Distribution） │
│  ・ルーティング・QoS・セキュリティポリシー │
│  ・部門別集約、VLAN間ルーティング          │
│  ・L3スイッチ使用                         │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│  アクセス層（Access Layer）              │
│  ・エンドデバイス（PC・IP電話・AP）接続  │
│  ・VLAN割り当て・PoE・ポートセキュリティ │
│  ・L2スイッチ使用                        │
└─────────────────────────────────────────┘
📌 2層モデル（Collapsed Core）
小〜中規模ネットワークでは、コア層とディストリビューション層を1つのL3スイッチに統合（コラプスドコア方式）することが多い。コストを抑えられる反面、スケーラビリティは低下する。

各機器のドメイン分割まとめ

機器         コリジョンドメイン  ブロードキャストドメイン
─────────────────────────────────────────────
ハブ         分割しない ✗         分割しない ✗
スイッチ     ポートごとに分割 ○   分割しない ✗ (VLANで○)

✏️ 確認問題（第1-1章）

Q1. ブロードキャストドメインを分割できる機器はどれか？
正解：C（ルータ）
ルータのみがブロードキャストドメインを分割できます。ハブとリピータはL1で動作しコリジョンドメインすら分割しません。L2スイッチはコリジョンドメインは分割しますが、ブロードキャストドメインは分割しません（VLANを使えば分割できます）。
Q2. L2スイッチが使用する識別子（アドレス）として正しいのはどれか？
正解：A（MACアドレス）
L2スイッチはMACアドレス（48ビット、16進数）を使ってフレームを転送します。IPアドレスを使うのはL3（ルータ・L3スイッチ）です。
Q3. 現代のデータセンターで最も一般的に採用されるトポロジはどれか？
正解：C（スパイン・リーフ型）
スパイン・リーフ型はすべてのリーフスイッチがすべてのスパインスイッチに接続される2層構成です。等コスト経路が多数存在し、データセンターでのトラフィック増加にも対応しやすい設計です。
Q4. シスコの3層ネットワーク設計モデルで、VLANポリシーやQoSを適用する層はどれか？
正解：B（ディストリビューション層）
ディストリビューション層はルーティング・QoS・セキュリティポリシーを担います。コア層は高速転送に専念し、アクセス層はエンドデバイスの接続を担います。
Q5. ハブを使用したネットワークの問題点として最も適切なものはどれか？
正解：A（コリジョンの発生）
ハブはL1機器で、受信したビット信号を全ポートに中継するだけです。全機器が同一コリジョンドメインに属するため、複数機器が同時に送信するとコリジョン（データ衝突）が発生します。
ブロードキャストストーム（D）はL2ループで発生する問題であり、ハブの主な問題ではありません。
Q6. IPSとIDSの違いとして正しいのはどれか？
正解：D
IDS（Intrusion Detection System）は不正を検知してアラートを送るだけで通信は止めません（受動的）。IPS（Intrusion Prevention System）は不正を検知しリアルタイムでブロックします（能動的）。試験では「防止」（Prevention）= ブロックと覚えましょう。
Q7. 次のうち、LANの範囲として正しいものはどれか？
正解：B
LAN=Local Area Networkで企業オフィスや家庭内など「局所的な」ネットワーク。WAN=Wide Area Network（広域）、MAN=Metropolitan（都市圏）、PAN=Personal（個人周辺）。
Q8. コラプスドコア（Collapsed Core）設計の説明として正しいのはどれか？
正解：C
コラプスドコアはコア層とディストリビューション層を1台のL3スイッチに統合します。小〜中規模のネットワークでコストを抑えるために使われます。
