5-3 セキュリティの脅威と対策・VPN基礎

頻出概念 ネットワーク攻撃の分類・防御策・VPNの基礎を完全理解する

⚠️ネットワークセキュリティの脅威一覧

攻撃カテゴリ 攻撃名 仕組み 対策
偵察（Reconnaissance） ポートスキャン サーバーの開いているポートを調査（nmap等） IPS/IDS、不要サービスの無効化、ACL
パケットキャプチャ ネットワーク上のパケットを傍受（Wireshark等） 暗号化（SSH, HTTPS, VPN, WPA2/3）
アクセス攻撃 パスワード攻撃（ブルートフォース） 総当たりでパスワードを推測 パスワードポリシー、アカウントロック、MFA
辞書攻撃 よく使われるパスワードのリストで推測 複雑なパスワード、MFA
フィッシング 偽のメール/サイトで認証情報を窃取 ユーザー教育、メールフィルタ、MFA
中間者攻撃（MITM） 通信を傍受・改ざん（ARPスプーフィング等） 暗号化、証明書検証、DAI
DoS/DDoS攻撃 TCP SYNフラッド 大量のTCP SYNパケットでサーバーリソースを枯渇 SYN Cookie、レート制限、IPS
DDoS（分散型DoS） ボットネットから一斉に攻撃 DDoS防御サービス、ISP連携
L2攻撃 MACフラッディング 大量の偽MACアドレスでCAMテーブル溢れ ポートセキュリティ
VLANホッピング（ダブルタギング） 802.1Qタグを二重に付与して他VLANへ不正アクセス ネイティブVLANをVLAN 1以外に変更
VLANホッピング（DTP悪用） DTPでトランク確立して全VLANトラフィック取得 switchport mode access, switchport nonegotiate
ソーシャルエンジニアリング プリテキスティング 偽の身分を名乗って情報を聞き出す セキュリティ教育、認証プロセス
ショルダーサーフィン 後ろから画面を覗き見る プライバシースクリーン、環境対策
マルウェア ランサムウェア データを暗号化して身代金を要求 バックアップ、アンチマルウェア、パッチ適用
トロイの木馬 正常なソフトに偽装してバックドアを設置 アンチマルウェア、信頼できるソースのみ使用
🚨 VLANホッピング攻撃の防止策（頻出！）
  1. 使用しないポートはshutdownして未使用VLANに割り当て
  2. アクセスポートは明示的にswitchport mode accessを設定
  3. トランクポートではswitchport nonegotiateでDTPを無効化
  4. ネイティブVLANをVLAN 1以外に変更（ダブルタギング対策）
  5. トランクで許可するVLANをswitchport trunk allowed vlanで限定

🔑パスワード管理のベストプラクティス

# パスワードの暗号化
Router(config)# service password-encryption           # type 7暗号化（弱い・容易に復号可能）
Router(config)# enable secret MyStr0ngP@ss           # type 5/8/9暗号化（MD5以上・推奨）
# enable secret は enable password より強い暗号化。両方設定時はsecretが優先

# パスワードの最小文字数設定
Router(config)# security passwords min-length 10

# ログイン試行回数制限（ブルートフォース対策）
Router(config)# login block-for 120 attempts 3 within 60
# 60秒以内に3回失敗したら120秒間ブロック

# ログインバナー（法的警告）
Router(config)# banner motd #
Unauthorized access is prohibited. All activities are monitored and logged.
#

# VTYアクセス制限（ACLでSSH接続元を限定）
Router(config)# access-list 99 permit 10.0.0.0 0.0.0.255
Router(config)# line vty 0 4
Router(config-line)# access-class 99 in
Router(config-line)# exec-timeout 5 0              # 5分無操作でセッション切断

🔐VPN基礎 ── 安全なリモートアクセス

VPN（Virtual Private Network）は、インターネットなどの公共ネットワーク上に暗号化されたトンネルを作成して安全に通信する技術です。

VPNの2つの主要タイプ

比較項目 Site-to-Site VPN Remote Access VPN
接続パターン 拠点間（ルータ対ルータ） 個人端末からネットワークへ
利用者 拠点全体（自動・透過的） 個人ユーザー（VPNクライアント起動）
用途 本社⇄支店の常時接続 在宅勤務・出張先からの社内アクセス
プロトコル IPsec, GRE over IPsec SSL VPN, IPsec (Cisco AnyConnect)
設定場所 両端のルータ/ファイアウォール サーバー側 + クライアントソフト

IPsec ── VPNの暗号化フレームワーク

IPsecの主要プロトコル

プロトコル 機能 IPプロトコル番号
ESP（Encapsulating Security Payload） 暗号化 + 認証 + 完全性 50
AH（Authentication Header） 認証 + 完全性のみ（暗号化なし） 51
IKE（Internet Key Exchange） 鍵交換の自動化（フェーズ1+2） UDP/500

実務では ESP がほぼ常に使用されます（暗号化が含まれるため）。AHは暗号化がないのでNAT環境で使えない等の制限があります。

GRE over IPsec

GRE（Generic Routing Encapsulation）:
  ・トンネリングプロトコル（パケットをカプセル化）
  ・マルチキャストやルーティングプロトコルを通せる
  ・暗号化機能がない → IPsecと組み合わせて使用

GRE over IPsec:
  ・GREでカプセル化（マルチキャスト対応）
  ・IPsecで暗号化（セキュリティ確保）
  ・Site-to-SiteでOSPF等のルーティングプロトコルを暗号化して運ぶのに最適

  [元のパケット] → [GREヘッダ追加] → [IPsecで暗号化] → 送信

✏️ 確認問題（第5-3章）

Q1. VLANホッピング攻撃を防ぐための対策として正しくないのはどれか？
正解：C（正しくない対策）
VLAN 1はダブルタギング攻撃で悪用されやすいため、ネイティブVLANはVLAN 1以外に変更すべきです。
Q2. enable secretとenable passwordの両方が設定されている場合、どちらが使用されるか？
正解：A
enable secretはMD5以上のハッシュで保存され、enable password（type 7、容易に復号可能）より安全です。IOSはenable secretを優先します。
Q3. Site-to-Site VPNの説明として正しいのはどれか？
正解：D
Site-to-Site VPNは拠点間のゲートウェイ装置同士で暗号化トンネルを張ります。ユーザーは意識せず透過的に通信できます。A/Cの個人端末からの接続はRemote Access VPNです。
Q4. IPsecでデータの暗号化と認証の両方を提供するプロトコルはどれか？
正解：B（ESP）
ESPは暗号化+認証+完全性を提供します。AHは認証+完全性のみ（暗号化なし）。IKEは鍵交換プロトコル。GREはカプセル化のみ（暗号化なし）。
Q5.【シナリオ】在宅勤務の従業員が自宅のPCから安全に社内ネットワークにアクセスする必要がある。最適なVPNタイプはどれか？
正解：C
Remote Access VPNは個人端末からの接続に最適です。Cisco AnyConnect等のVPNクライアントをインストールし、SSL/IPsecで暗号化接続します。Site-to-Siteは拠点間の常時接続用です。
